### 14. Code Review Checklist (Review code tự động)
**Command:** `/code-review`
**Mô tả:** Chạy checklist đầy đủ cho file hiện tại

**Workflow checks:**
- ✅ Naming conventions
- ✅ Code structure (theo conventions)
- ✅ Security issues
- ✅ Error handling
- ✅ Comments/documentation
- ✅ Performance issues
- ✅ Best practices
