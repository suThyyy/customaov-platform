# Tài Liệu Nghiệp Vụ

Thư mục này chứa tài liệu nghiệp vụ tổng quan (business requirements, process flows).

## Cách tổ chức
- Mỗi quy trình/module một file
- Đặt tên: `[ten-quy-trinh].md`
- Nội dung: mô tả quy trình, flowcharts, business rules, roles

## Khác biệt với `dac-ta/`
- `nghiep-vu/` — Tổng quan quy trình, luồng nghiệp vụ (high-level)
- `dac-ta/` — Đặc tả chi tiết từng chức năng (detailed specs)
