## Yêu cầu
- `base-backend-api/package.json`: name `@customaov/api`, private, `"type": "module"`, engines node >=20.
  - Scripts: `build` (tsc → `dist`), `dev` (`tsx watch src/server.ts`), `start`, `test` (`vitest run`), `typecheck` (`tsc --noEmit`).
  - Thư viện (đã được Owner duyệt, PRD mục 6): `fastify` 5, `@fastify/cookie`, `@fastify/rate-limit`, `zod`; dev: `tsx`, `typescript`, `vitest`, `@types/node`. **Không thêm gì khác.** `@fastify/websocket`, `drizzle-*`, `pg`, `@electric-sql/pglite` để task sau thêm.
- `src/config.ts`: đọc env bằng zod, có `HOST` (mặc định `127.0.0.1`), `PORT` (mặc định `6174`), `LOG_LEVEL`, `NODE_ENV`. Sai env thì báo lỗi rõ ràng.
- `src/app.ts`: `buildApp(opts)` trả về Fastify instance (không listen) để test bằng `inject`. Đăng ký `@fastify/cookie`.
  - Logger pino có `redact` cho: `req.headers.cookie`, `req.headers.authorization`, `req.headers["x-csrf-token"]`, `res.headers["set-cookie"]`, `*.password`, `*.token`.
  - Error handler trả JSON `{ error: { code, message } }`, không lộ stack khi `NODE_ENV=production`.
- `src/server.ts`: listen theo config, tắt êm khi SIGINT/SIGTERM.
- `GET /health` → `200 { status: "ok" }`.
- Test (`src/**/*.test.ts`):
  - `/health` OK;
  - route lạ → 404 JSON đúng định dạng;
  - logger redact: log một request có cookie và header `x-csrf-token`, chắc chắn giá trị không xuất hiện trong output log.
- `tsconfig.json` strict, `module`/`moduleResolution` `NodeNext`, target ES2022.
- `README.md` ngắn trong `base-backend-api`: chạy dev, test, biến env.
