# E4-T06 – E2E chế độ api: luồng phòng 10 người

## Mục tiêu
Script `base-frontend-web/scripts/e2e-rooms-api.mjs <webUrl>` (Playwright thuần, như `e2e-auth-api.mjs`) chạy luồng thật trên backend thật đã seed.

## Được sửa
Script mới và `package.json` frontend (thêm script `test:e2e:rooms`). Nếu phát hiện bug sản phẩm: **không sửa**, ghi vào báo cáo (Lead sẽ giao sửa).

## Luồng
1. Đăng ký 10 tài khoản mới qua API (fetch kèm CSRF) hoặc UI.
2. Host tạo phòng 5v5 công khai qua UI `/rooms/new`.
3. 9 người vào phòng (API). Mở 2 context trình duyệt (host và 1 người chơi) ở `/rooms/<code>`.
4. Host bấm "Chia lại" (random): cả 2 trình duyệt thấy đội 5–5 cập nhật qua WebSocket, không cần tải lại.
5. Người chơi chat: host thấy tin realtime.
6. Host đổi chỗ 1 người, mời ra 1 người: người bị mời ra bị điều hướng về `/dashboard`.
7. Host "Xuất kết quả" (clipboard) rồi ghi kết quả: phòng `finished`; hồ sơ người thắng có `customMatches` +1; dashboard có hoạt động "result".
