## Yêu cầu
**Schema (mục 9.2):**
- `room_members.active boolean not null default true` + partial unique index `(user_id) WHERE role='player' AND active`.
- `tournament_team_members.active boolean not null default true`. Bỏ unique `(tournament_id, user_id)`, thay bằng partial unique index `(tournament_id, user_id) WHERE active`.
- `rooms.join_key`: 16 byte base64url (seed sinh ngẫu nhiên cho phòng private).
- `bracket_matches`: thêm `is_bye boolean not null default false` (mục 9.3).
- Seed:
  - set `active` đúng: phòng `finished` thì false; đội `rejected`/`withdrawn` thì false;
  - dữ liệu cũ vẫn giữ (suthy chỉ ở AOV-1024, v.v.).

**Contracts:**
- 9.1:
  - `RoomRestrictedSchema` (= RoomSummary + `restricted: true`);
  - `GET /rooms/:code` response là union với `RoomDetail & {restricted: false, shareUrl?: string}` (`shareUrl` chỉ host thấy);
  - WS `subscribe` có `key?`;
  - WS server message `{type:'error', code, room}`.
- 9.3: `BracketSlot = {team: Team | null, score: number | null, bye: boolean}`. `ScheduledMatch.time` cho phép "Chưa xếp lịch".
- 9.6:
  - `formatTeamsText`: lane `null` → "Chưa chọn";
  - `CreateMessageBody.text` trim rồi `min(1)`.

**Test:**
- partial unique index:
  - cùng user là player active ở 2 phòng → lỗi;
  - inactive thì được.
- đội rejected cho phép thành viên đăng ký lại đội khác;
- `is_bye`;
- contracts mới có ca hợp lệ/sai.
