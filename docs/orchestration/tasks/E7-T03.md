## Mục tiêu
Theo PRD mục 8:
- chạy toàn bộ app local bằng **một lệnh**;
- bộ test backend đã chạy được trên Postgres thật.

## Việc
1. **Test trên Postgres.** `docker compose up -d` (Docker đã cài). Chạy migration + seed + **toàn bộ test backend** trên Postgres.
   - Nếu test hiện chỉ dùng PGlite: thêm biến môi trường `TEST_DATABASE_URL`. Mặc định vẫn là PGlite; khi có biến thì dùng Postgres, mỗi file test dùng schema riêng hoặc truncate dữ liệu.
   - Lỗi nào chỉ xảy ra trên Postgres thì sửa và ghi rõ.
2. **Lệnh chạy một bước `npm run dev:all`** ở gốc, không thêm thư viện:
   - `scripts/dev-all.mjs` spawn API (PGlite file, tự seed nếu DB trống) và web (chế độ api);
   - đặt đúng `API_TARGET` và `ALLOWED_ORIGINS`;
   - bấm Ctrl+C thì tắt cả hai process.
3. **`README.md` gốc** gồm các mục:
   - yêu cầu môi trường;
   - chạy nhanh: `npm ci && npm run dev:all`;
   - tài khoản demo `suthy` / `customaov123`;
   - chạy test và e2e. Lưu ý: rate limit lưu trong bộ nhớ, nên mỗi script e2e api cần một backend vừa khởi động;
   - chạy với Postgres;
   - biến môi trường: `DATABASE_URL`, `CSRF_SECRET`, `ALLOWED_ORIGINS`, `NODE_ENV`.
4. Chạy xong thì `docker compose down`.

## Được sửa
`package.json` gốc (phần scripts), `scripts/dev-all.mjs`, `README.md`, `docker-compose.yml` (nếu cần), helper test backend (`src/test/**`, `vitest.config.ts`), `database/README.md`.

Không thêm thư viện, không đổi schema.

## Verify
- Gốc: `npm ci && npm run build && npm run lint && npm test`.
- Backend trên Postgres: `TEST_DATABASE_URL=... npm test --workspace @customaov/api`.
- `npm run dev:all` chạy được; probe đăng nhập `suthy` thành công.
- Commit, rồi gửi `worker_done` kèm đầu ra rút gọn.
