## Kiểm tra
1. Phạm vi `git diff integration/mvp...HEAD --stat`:
   - được phép: `src/app.ts`, `src/server.ts`, `src/config.ts`, `src/auth/**`, `src/test/**`, `base-backend-api/vitest.config.ts` (Lead chấp nhận: timeout 30s cho PGlite+scrypt);
   - không có thư viện mới.
2. Cookie `sid`:
   - `HttpOnly; SameSite=Lax; Path=/`, `Secure` khi production;
   - DB chỉ lưu SHA-256;
   - hạn 30 ngày, trượt khi còn < 15 ngày;
   - logout xoá phiên.
3. CSRF:
   - định dạng `nonce.HMAC(CSRF_SECRET, nonce:(sidHash|anon))`;
   - áp cho **mọi** POST/PUT/PATCH/DELETE dưới `/api` (kể cả login/register/logout);
   - kiểm header == cookie **và** chữ ký đúng với phiên hiện tại, so sánh `timingSafeEqual`;
   - login/logout/register cấp cookie mới; `/me` đặt cookie khi thiếu;
   - production thiếu `CSRF_SECRET` → khởi động lỗi.
4. Rate limit: login 5/phút/IP **và** 10/15 phút theo IP+username; register 5/giờ/IP; trả 429 `RATE_LIMITED` đúng dạng lỗi.
5. Login sai trả thông báo chung, có chạy scrypt giả khi không có user.
6. Log: không chứa password, cookie, `sid`, csrf, set-cookie; không log body `/api/auth/*`. Tự viết 1 test tạm hoặc đọc test có sẵn để xác nhận. **Không commit test tạm.**
7. Contracts: response khớp schema (`me`, `register`, `login`).
8. Chạy ở gốc: `npm install`, `npm run build && npm run lint && npm test` (**toàn bộ**, coder chưa chạy `npm test` gốc). Smoke: `cd base-backend-api && $env:PORT=6181; npx tsx src/server.ts` (nền) → `/health`, `/api/auth/csrf`, `/api/auth/me`, rồi tắt **đúng process đó** (theo PID).
9. Tìm lỗ hổng:
   - CSRF bypass qua method HEAD/OPTIONS hoặc content-type khác;
   - user enumeration qua thông báo lỗi register;
   - fixation phiên: login phải tạo token mới.
