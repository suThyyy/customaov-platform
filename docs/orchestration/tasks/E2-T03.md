## Yêu cầu
- Cấu trúc giống `packages/team-core`: name `@customaov/contracts`, private, ESM, build bằng `tsc` → `dist`, exports `types` + `import`. Scripts `build`, `test` (`node --test` như team-core, **hoặc** vitest), `typecheck`.
- Dependency: chỉ `zod` (đã duyệt). Dev: `typescript`, `@types/node` cùng phiên bản với team-core.
- Nội dung (chia file theo nhóm `auth.ts`, `users.ts`, `rooms.ts`, `tournaments.ts`, `activity.ts`, `common.ts`, `index.ts`):
  - Schema + type cho mọi body/query/response ở API.md mục 2–6, gồm `ErrorBody`, `ErrorCode`, `Paginated<T>`, các sự kiện WebSocket (`WsClientMessage`, `WsServerMessage`).
  - Ràng buộc đúng như API.md (độ dài, regex username, BO hợp lệ, `teamCount` 4/8/16, members đúng 5, subs 0–2, thứ tự ngày…).
  - Hàm thuần dùng chung:
    - `normalizeVi` (chép đúng hành vi của `base-frontend-web/src/lib/text.ts`);
    - `moveMember`, `removeMember`, `formatTeamsText` (chép từ `src/lib/room.ts`, đổi sang kiểu của contracts, giữ nguyên luật và thông báo tiếng Việt);
    - `isValidSeriesScore(series, a, b)`;
    - `ROOM_PERMISSIONS`/`can` (chép từ `room.ts`).
  - Hằng: `CSRF_HEADER = 'x-csrf-token'`, `CSRF_COOKIE = 'csrf'`, `SESSION_COOKIE = 'sid'`.
- Test:
  - mỗi schema có ít nhất 1 ca hợp lệ và 1 ca sai;
  - `moveMember` có đủ 4 nhánh (đổi chỗ, chuyển sang, đội đầy, người không còn trong phòng);
  - `normalizeVi` với chữ có dấu, chữ "đ/Đ";
  - `isValidSeriesScore` cho BO1/3/5.
