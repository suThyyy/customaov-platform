## Mục tiêu
Danh sách lỗi P0/P1/P2 của MVP ở **cả hai chế độ** mock và api, đủ chi tiết để agent khác sửa.

## Được sửa
Chỉ tạo `docs/orchestration/reviews/E7-T01-audit.md` và commit file đó. Không sửa code.

## Phạm vi audit
1. **Bảo mật backend** (đọc code `base-backend-api/src/**` theo `.agent/rules/04-security-rules.md` và API.md mục 2, 9):
   - mọi route ghi có CSRF + kiểm quyền;
   - IDOR (sửa hoặc xem dữ liệu của người khác);
   - phòng private bị lộ (REST và WS);
   - rate limit;
   - log có lộ bí mật không;
   - lỗi 500 có lộ stack không;
   - input không được validate.
2. **Nhất quán dữ liệu:** cùng một phòng/giải hiển thị giống nhau ở dashboard, trang chi tiết, tìm kiếm, hồ sơ.
3. **UX theo AGENTS.md** ở 375/768/1280/1440, cả mock lẫn api:
   - không cuộn ngang;
   - 1 nút vàng mỗi khung nhìn;
   - mỗi trang đúng 1 `<h1>`;
   - focus và bàn phím;
   - `ListStatus` khi loading/error/empty;
   - nhãn tiếng Việt.
4. **Luồng chính chế độ api** (chạy các script e2e có sẵn: `e2e-auth-api`, `e2e-rooms-api`, `e2e-tournament-api`). Rate limit lưu trong bộ nhớ, nên **khởi động lại API (seed mới) trước mỗi script**. Đặt `ALLOWED_ORIGINS=http://localhost:5212` cho backend.

## Cách chạy
- `npm ci`
- Mock: `npx vite --port 5211 --strictPort`.
- Api:
  - `cd base-backend-api && npm run db:seed && ALLOWED_ORIGINS=http://localhost:5212 PORT=6211 npx tsx src/server.ts`;
  - `API_TARGET=http://127.0.0.1:6211 VITE_DATA_SOURCE=api npx vite --port 5212 --strictPort`.
- Probe Playwright tạm: đặt `scripts/.ten-tam.mjs`, xoá sau khi chạy.
- Tắt server theo PID, xoá `.data`.
