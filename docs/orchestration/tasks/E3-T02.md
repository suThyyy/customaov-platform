## Thiết kế
- `src/api/source.ts`: `const DATA_SOURCE = import.meta.env.VITE_DATA_SOURCE === 'api' ? 'api' : 'mock'`.
- `src/api/client.ts` (http):
  - `fetch` với `credentials: 'include'`;
  - request ghi tự gắn header `x-csrf-token` lấy từ cookie `csrf` (hằng từ `@customaov/contracts`). Chưa có cookie thì gọi `GET /api/auth/csrf` trước;
  - parse lỗi `{error:{code,message}}` thành `ApiError` (có `code`, `status`);
  - response parse bằng schema contracts.
- `src/api/endpoints.ts`: hàm cho mọi endpoint ở API.md mục 2–6, ký hiệu kiểu bằng contracts.
- `src/api/map.ts`: ánh xạ kiểu contracts sang kiểu UI hiện có (`Player`, `Room`, `Tournament`, `TournamentDetail`, `UserProfile`, `Activity`…), để component đổi ít nhất.
- `src/api/mock.ts`: cùng interface, trả dữ liệu `src/mocks` (Promise), **giữ nguyên** hành vi `?mock=loading|error|slow` (`useMockStatus`).
- `src/api/hooks.ts`: `useRooms(params)`, `useRoom(code)`, `useTournaments(params)`, `useTournament(slug)`, `useProfile(username?)`, `useActivities()`, `useSearch(q)`. Mỗi hook trả `{status: 'loading'|'error'|'ready', data, retry}` và tương thích `ListStatus`. Tự viết bằng `useEffect` + `AbortController`. Cache nhỏ trong bộ nhớ theo key là đủ.
- Đổi các trang (`HomeUser`, `HomeGuest`, `Tournaments`, `TournamentDetail`, `RoomDetail`, `CreateRoom`, `Profile`, `SearchDialog`…) sang dùng hook. Hành động ghi (chia đội, chat…) giữ nguyên logic cục bộ hiện tại; các task E4/E5 sẽ nối API sau.
- Auth chưa đổi trong task này (E3-T03 làm).
