## Nội dung bắt buộc (ngắn gọn, tiếng Việt, ví dụ code TypeScript thật của repo)
- **Core:**
  - TypeScript strict, ESM, Node 22, Fastify 5;
  - cấu trúc `src/{app,server,config}.ts`, `src/routes/<nhóm>.ts`, `src/services/`, `src/db/`, `src/auth/`;
  - `buildApp()` không listen.
- **Hợp đồng:** mọi request/response validate bằng schema trong `@customaov/contracts`. Không tự định nghĩa lại kiểu. API đổi thì sửa `docs/product/API.md` trước.
- **Route/controller:**
  - lỗi theo dạng `{error:{code,message}}` (mã ở API.md mục 1);
  - phân trang `{items,total,page,pageSize}`;
  - kiểm quyền ở server (chủ phòng/BTC).
- **Service:** logic nghiệp vụ thuần, nhận `db`; thao tác nhiều bảng phải trong transaction; dùng `team-core` cho chia đội, không viết lại thuật toán.
- **DB (Drizzle):**
  - schema ở `src/db/schema.ts`;
  - migration bằng `drizzle-kit generate` vào `database/migrations/` (không sửa tay migration đã merge);
  - PGlite cho dev/test, Postgres khi production;
  - không dùng extension;
  - **thay đổi schema phải ghi DECISIONS.md**.
- **Bảo mật** (Owner chốt):
  - cookie `sid` httpOnly + SameSite=Lax (+Secure ở production);
  - CSRF double-submit cho mọi request ghi;
  - rate-limit đăng nhập/đăng ký/chat;
  - scrypt;
  - redact log (cookie, set-cookie, authorization, x-csrf-token, password, token);
  - không log body `/api/auth/*`;
  - WS chỉ đẩy server→client, kiểm `Origin`.
- **Test:** Vitest + `app.inject` + PGlite `memory://`. Mỗi endpoint có test cho thành công, 401/403, 400.
- Workflow: "thêm endpoint" (contracts → route → service → test), "thêm migration", "code review" (checklist bảo mật ở trên).
