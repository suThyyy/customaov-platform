# Tài Liệu Tích Hợp

Thư mục này chứa tài liệu tích hợp với hệ thống bên ngoài (external APIs, third-party services).

## Cách tổ chức
- Mỗi hệ thống bên ngoài một file/folder
- Đặt tên: `[ten-he-thong].md`
- Nội dung: API specs, authentication, sequence diagrams, error handling

## Ví dụ
```
tich-hop/
├── payment-gateway.md
├── email-service.md
├── sso-integration.md
└── file-storage-minio.md
```
